# CS210
SNHU CS210 repository

# Summarize the project and the problem it was solving.

In this project, I created an investment calculator for Airgead Banking. The goal was to help users see how their money could grow over time using compound interest. The program lets users enter investment information and compares growth with and without monthly deposits so they can understand the impact of investing.

# What did you do particularly well?

I think I did a good job separating the code into different functions and using a class to keep everything organized. I also spent time testing different calculations to make sure the numbers were accurate. Once I finished coding, the output was correct and easy to read.

# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One improvement my code could have had was input validation. Right now, the program assumes the user enters valid values. Adding checks for things such as negative numbers would help make the program more reliable and prevent errors.

# Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

For me, the most challenging piece of code to write was making sure the compound interest calculations were correct. While I was testing my code, I kept noticing the two reports were producing different results even when I typed 0 for the monthly deposit. Looking back through my code, I realized I had used a plus sign instead of a multiplication sign when calculating monthly interest. I fixed this issue by testing different values and comparing the output. The ZyBooks chapters and constant testing helped me find and fix the problem. It also taught me the importance of debugging.

# Which skills from this project will be particularly transferable to other projects or course work?

This project helped me become more comfortable working with classes, functions, loops, and calculations in C++. It also gave me confidence when debugging because I repeatedly looked through my code and tested each component. These skills will definitely help me in my future programming endeavors.

# How did you make this program maintainable, readable, and adaptable?

I made the program easier to read by using appropriate variable names, adding comments, and separating each task into different functions. I also used a class to keep related data and calculations together. This kept my code organized and easy to review.
